# 🎵 Music Transfer — Яндекс Музыка → YouTube Music

Приложение с графическим интерфейсом для переноса понравившихся треков в **YouTube Music**.  
Изначально создано для Яндекс Музыки, но подходит для **любой платформы** — нужен лишь файл со списком треков в поддерживаемом формате.

## 🖥 Интерфейс

Приложение разделено на две вкладки:

| Вкладка | Что делает |
|---|---|
| ❶ Яндекс Музыка | Загружает понравившиеся треки по токену и сохраняет в xlsx / txt / csv |
| ❷ YouTube Music | Читает файл треков и лайкает их в YouTube Music |

---

## ❶ Вкладка — Яндекс Музыка

### Как получить токен

**Способ 1 — Автоматически через сайт:**

Перейди по ссылке и скопируй токен:
```
https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d
```

**Способ 2 — Через DevTools:**

1. Открой [music.yandex.ru](https://music.yandex.ru) или десктопное приложение и войди в аккаунт
2. Нажми **Ctrl + Shift + I** (DevTools)
3. Перейди на вкладку **Application**
4. В левой панели: **Storage → Local Storage 
5. Найди ключ **`oauth`** → скопируй значение поля **`value`** — это и есть твой токен

### Использование

1. Вставь токен в поле и нажми **«Загрузить треки из Яндекса»**
2. Дождись окончания загрузки (прогресс-бар)
3. Выбери формат файла: `xlsx`, `txt` или `csv`
4. Нажми **«Сохранить файл»**

## ❷ Вкладка — YouTube Music

> ℹ️ **Можно переносить треки с любой платформы**, не только с Яндекса.  
> Достаточно подготовить файл со списком треков в одном из форматов ниже.

### Поддерживаемые форматы файла с треками

**XLSX / CSV** — два столбца: `artist` и `title`

| artist | title |
|---|---|
| **** | ****** |
| ***| ******** |

**TXT** — каждая строка в формате:
```
Исполнитель — Название трека
```

### Как создать `browser.json` (авторизация YouTube)

1. Открой [music.youtube.com](https://music.youtube.com) и войди в аккаунт
2. Нажми **F12** (DevTools) → вкладка **Network**
3. В поиске запросов введи `browse`, затем нажми **Ctrl+R** (обновить страницу)
4. Кликни на любой запрос `browse` (тип POST) → **Headers → Request Headers**
5. Скопируй следующие заголовки:

```
accept: */*
accept-encoding: gzip, deflate, br
accept-language: ru-RU,ru;q=0.9
authorization: SAPISIDHASH ...
content-type: application/json
cookie: ОЧЕНЬ_ДЛИННАЯ_СТРОКА
user-agent: Mozilla/5.0 ...
x-goog-authuser: 0
x-origin: https://music.youtube.com
```

6. В терминале выполни:
```bash
ytmusicapi browser
```
7. Вставь скопированные заголовки и нажми **Enter дважды** или **Enter, Ctrl+Z, Enter**— создастся файл `browser.json` в директории в которой вы находитесь

> ⚠️ Куки действуют в течение ограниченного времени. Если появилась ошибка **401 Unauthorized** — повтори шаги выше и пересоздай `browser.json`. Приложение автоматически остановится на месте ошибки и продолжит с него после перезапуска.

### Использование

1. Выбери `browser.json` через кнопку 📂
2. Выбери файл с треками
3. Нажми **«▶ Начать перенос»**
4. При необходимости — **«⏹ Стоп»** для паузы
5. Прогресс сохраняется автоматически в `progress.txt` — при повторном запуске уже перенесённые треки пропускаются
